# Galaxy Cursor Installer

Instaladores desenvolvidos pelo **Canal WINchester** para facilitar a instalação dos cursores personalizados do projeto Galaxy Cursor no Windows.

✨ Aplique os cursores com poucos cliques, sem precisar configurar manualmente cada ponteiro do mouse!

**📁 Arquivos · 🖱️ Cursores · 🔄 Restaurar padrões · 🔗 Projeto original**

---

## 🖱️ Sobre o Projeto

O [Galaxy Cursor](https://github.com/sebastianheder01/Galaxy-Cursor) é um projeto de personalização que oferece cursores para Windows, incluindo versões animadas e clássicas.

O objetivo deste repositório é simplificar a instalação desses cursores por meio de scripts `.bat` que automatizam a configuração dos ponteiros do mouse.

### ✨ O que está incluído?

| Arquivo | Descrição |
| --- | --- |
| 📄 `instalar cursores animados.bat` | Instala os cursores animados do Galaxy Cursor |
| 📄 `instalar cursores classic.bat` | Instala os cursores da versão Classic |

Os dois instaladores também permitem restaurar os cursores padrão do Windows.

---

## 📥 Como Instalar

### 1️⃣ Baixe os cursores originais

Acesse o repositório oficial do Galaxy Cursor e baixe a versão mais recente disponível:

🔗 [Galaxy Cursor — Repositório Oficial](https://github.com/sebastianheder01/Galaxy-Cursor)

Extraia os arquivos dos cursores para uma pasta permanente no computador.

### 2️⃣ Baixe os instaladores

Acesse este repositório e clique em **Code → Download ZIP** para baixar os scripts.

🔗 [Galaxy Cursor Installer — Download](https://github.com/winchestercanal/galaxy-cursor-installer)

Extraia o conteúdo do ZIP.

### 3️⃣ Organize os arquivos

Coloque o instalador escolhido na mesma pasta dos arquivos de cursores correspondentes.

- **Cursores animados:** arquivos `.ani`
- **Cursores Classic:** arquivos `.cur` e `.ani`, conforme os arquivos disponibilizados nessa versão

Mantenha os arquivos juntos durante a instalação.

### 4️⃣ Execute o instalador

Dê dois cliques no arquivo `.bat` correspondente à versão desejada.

No menu que será exibido, escolha:

- `1` — Instalar os cursores
- `2` — Restaurar os cursores padrão do Windows

Aguarde a conclusão do processo. O instalador configura os ponteiros e atualiza a seleção de cursores do sistema.

---

## 🔄 Restaurar os Cursores Padrão

Caso queira voltar à aparência original do Windows, execute novamente o instalador utilizado e selecione a opção **2 — Restaurar os cursores padrão do Windows**.

O script restaura as configurações padrão dos ponteiros e remove os arquivos instalados pelo respectivo instalador.

---

## ⚠️ Observações Importantes

- Os arquivos de cursores precisam estar na mesma pasta do instalador correspondente.
- Mantenha os cursores em uma pasta permanente para evitar referências a arquivos que foram movidos ou excluídos.
- Os instaladores alteram as configurações de ponteiros do usuário atual do Windows.
- O projeto não é o criador original dos cursores; os arquivos de personalização pertencem ao projeto Galaxy Cursor.
